# Wiring

## AM2302 / DHT22 Temperature and Humidity Sensor

| Sensor Pin | ESP32 Pin |
|---|---|
| VCC | 3.3V |
| GND | GND |
| DATA | GPIO 4 |

## AM312 PIR Motion Sensor

| Sensor Pin | ESP32 Pin |
|---|---|
| VCC | 3.3V |
| GND | GND |
| OUT | GPIO 18 |

## BH1750 Light Sensor

| Sensor Pin | ESP32 Pin |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SDA | GPIO 21 |
| SCL | GPIO 22 |
| ADDR | Not connected |

## Simulated AC LED

| Component | ESP32 Pin |
|---|---|
| LED positive side | GPIO 26 through resistor |
| LED negative side | GND |
